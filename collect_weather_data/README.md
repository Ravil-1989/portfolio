### Описание проекта
---
В нашем распоряжении данные погодные данные для городов РФ на сайте https://open-meteo.com.

### Цель исследования
---
Создание погодного скрипта, который собирает погодные данные для городов РФ с сайта https://open-meteo.com, обрабатывает их и сохраняет в базу данных. На основании полученных погодных данных построить визуализацию в Yandex DataLens.

### Общий вывод
---
#### Ключевые моменты ETL-процесса в проекте

#### 📥 Extract (Извлечение данных)
- **Веб-скрейпинг**: С использованием `BeautifulSoup` получен список городов России с атрибутами (регион, население) из Wikipedia.
- **Работа с API**: Написаны скрипты для выгрузки исторических погодных данных за 50+ лет через Open-Meteo API с обработкой лимитов и пагинации.

#### 🔄 Transform (Преобразование данных)
- **Геокодирование**: Для каждого города получены координаты (широта, долгота) через Nominatim (OpenStreetMap) для привязки к погодным данным.
- **Обогащение и очистка**: Данные проверены на дубликаты, дополнены высотой над уровнем моря (через OpenTopoData API) и приведены к единому формату с помощью `pandas`.

#### 📤 Load (Загрузка данных)
- **Разработческое хранилище**: Очищенные данные первоначально загружались в SQLite с оптимизацией производительности.
- **Промышленное хранилище**: Выполнена миграция данных в PostgreSQL. Сервер БД был развернут в WSL (Ubuntu), настроены доступ и базовые меры безопасности.
- **Результат**: Подготовленное хранилище данных стало источником для построения дашбордов в Yandex DataLens, что позволило визуализировать погодные тенденции. Дашборды можно посмотреть по <a href='https://datalens.yandex/fe071bz8rmjg0?tab=pLM'>ссылке</a>.
