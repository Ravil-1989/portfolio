### Описание проекта
---
Компания купила крупный сервис для чтения книг по подписке. В ней находится информация о книгах, издательствах, авторах, а также пользовательские обзоры книг. Эти данные помогут сформулировать ценностное предложение для нового продукта.

### Цель исследования
---
Проанализировать базу данных, сделать выводы и дать рекомендации для нового сервиса по чтению книг.

### Общий вывод
---
В результате исследовательского анализа данных подготовлены рекомендации для нового сервиса по чтению книг.
